# Le Koup’Faim — maquette du site

Maquette du site internet du kebab **Le Koup’Faim**, 16 rue du Général de Gaulle, 59400 Cambrai : carte en ligne et commande à emporter ou en livraison dans le Cambrésis.

Réalisée par **NK Digital** — nkdigital.fr

## Contenu

Un seul fichier, `index.html` (HTML, CSS et JavaScript, sans installation).

- Charte graphique du Koup’Faim : logo, orange #FF7A00, gris #3A3A3A, police Montserrat
- Broche de kebab en 3D (Three.js) qui tourne, illustrations des plats, animations
- Carte complète : formules menu, option frites, sauces, suppléments fromage ou viande, tacos à composer, extras boisson et dessert
- Panier, commande à emporter ou en livraison, créneaux horaires, précommande quand c’est fermé
- Zones de livraison dans le Cambrésis (4 zones, 15 km maximum, frais selon la distance)
- Code promo de première commande, bouton « Recommander », suivi de commande
- Écran cuisine (lien « Écran cuisine » en haut de page) pour faire avancer les commandes

## Maquette

Les prix sont affichés « X € » et les commandes restent dans le navigateur : rien n’est envoyé au restaurant. La version finale enverra les commandes à une base de données (Supabase) et imprimera les tickets en cuisine sur l’imprimante Star TSP100.
